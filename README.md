# AI Meeting Notes & Action Item Summarizer

An AI-powered web application that converts raw meeting transcripts and notes into high-level executive summaries, key decisions, and structured action items with assigned owners and due dates.

## Built With
- **Frontend / UI:** Streamlit
- **LLM API Engine:** Groq API (`llama-3.3-70b-versatile`)
- **Language:** Python 3.10+
